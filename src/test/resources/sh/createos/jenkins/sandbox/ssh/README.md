# Test key fixtures

Throwaway key pairs generated by `ssh-keygen` solely so `SshPublicKeysTest` can assert that
the derived public key matches what OpenSSH itself wrote. They authorize nothing, are not
used by any deployment, and are deliberately committed so the expected value comes from
OpenSSH rather than from a second copy of the code under test.

Regenerate with:

```sh
ssh-keygen -q -t ed25519  -N ''                          -C createos-test -f ed25519
ssh-keygen -q -t rsa -b 2048 -m PEM -N ''                -C createos-test -f rsa-pem
ssh-keygen -q -t ecdsa -b 256 -m PEM -N ''               -C createos-test -f ecdsa-pem
ssh-keygen -q -t ed25519  -N 'createos-test-passphrase'  -C createos-test -f ed25519-enc
ssh-keygen -q -t rsa -b 2048 -m PEM -N 'createos-test-passphrase' -C createos-test -f rsa-pem-enc
```
